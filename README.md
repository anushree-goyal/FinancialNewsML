# FinancialNewsML

An end-to-end machine-learning project investigating whether information
extracted from financial news can help characterize or predict subsequent
market reactions.

## Current milestone

Classical financial text classification baseline.

## Research question

Can machine-learning models extract useful information from financial news
about sentiment, event type, and subsequent market reactions?


## Process

Phase 1: Classical NLP (Natural Language Processing) Baseline

We use the 75% agreement subset of Financial PhraseBank to balance annotation reliability with dataset size. Higher-agreement subsets provide cleaner labels but fewer training examples, while lower-agreement subsets introduce more label ambiguity.
75agree keeps more realistic, mildly ambiguous financial language while still requiring strong agreement. (more data than allagree)
